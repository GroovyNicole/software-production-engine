# Changelog

Material changes to the playbook, standards, templates, and control interpretations are recorded here.

## 2026-07-14 - Reusable article-engine package

### Added

- Added `templates/article-engine/` as a complete, anonymized, copy-ready Node.js article pipeline.
- Added article-engine-specific engineering scope, quality gates, and a package manifest linked to the canonical modular software controls.
- Preserved fail-closed customization, grounded-claim validation, human-review state boundaries, offline tests, atomic storage, and optional cost-controlled golden evaluation.

## 2026-07-14 - Neutral modular standards and resumable project state

### Changed

- Replaced company-branded reusable guidance with organization- and project-neutral standards and templates.
- Split the 200 software controls into seven interlinked control modules plus a review-method module.
- Split the 150 website controls into eleven interlinked control modules and separated operating, architecture/CSS/accessibility, security/performance/content, testing/release, and prompt guidance.
- Added a short `AGENTS.md` coordinator template with linked, phase-split intake, account-boundary, phase-ledger, risk, and decision modules.
- Added phase-gated startup behavior so assistants ask only unanswered questions blocking the earliest incomplete phase.
- Added an optional singular `agent.md` redirect so the user's remembered command reliably opens authoritative `AGENTS.md` instructions.
- Superseded the monolithic generated Word publication with authoritative Markdown modules.
- Moved project-specific migration planning out of the neutral playbook; project copies remain in their own repositories.
