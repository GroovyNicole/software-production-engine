# Reusable project templates

Copy an entire template directory into a new repository, then follow that template's README and engineering guide. Do not mix files from unrelated templates.

## Available templates

- [Article engine](article-engine/README.md) - configurable Node.js pipeline for discovering, researching, scoring, and drafting grounded expertise articles for mandatory human review.

General project-state and review templates remain in this directory for projects that do not have a specialized package.
