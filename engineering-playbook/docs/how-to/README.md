# How-to guides

How-to guides are repeatable procedures that produce a verified result. Use `templates/how-to-guide-template.md`. Keep each guide focused and include failure handling, security considerations, rollback, and evidence of completion.

## Current guides

- [Start or resume a project with AGENTS.md](start-or-resume-project.md) - install the modular project-state system, ask phase-gated questions, and resume the earliest incomplete phase.

Project-specific implementation plans belong in their project repositories and link back to the neutral standards they apply.
