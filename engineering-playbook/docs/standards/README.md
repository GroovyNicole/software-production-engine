# Engineering standards

Standards are mandatory, testable, organization-neutral requirements. Each standard defines scope, evidence, exceptions, enforcement, ownership, and review behavior.

## Current standards

- [Professional Software Engineering Standard](software-engineering-standard.md) - index for the review method and seven interlinked modules containing controls 1-200.
- [Professional Website Engineering Standard](website-engineering-standard.md) - index for guidance modules and eleven interlinked modules containing controls 1-150.

## Loading rule

Load the index and only the modules required by the current phase or change. Initial and quarterly audits load every module and account for every control in order.

Project-specific facts and implementation decisions belong in the project repository, not in these standards.
