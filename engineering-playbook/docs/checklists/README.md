# Checklists

This directory is for concise gates used while performing work.

Checklists must link to their governing standard or how-to guide. They should identify who completes them, when they apply, what evidence is retained, and how exceptions are handled.

## Current checklists

- [Website Release Gate](website-release-gate.md) - required evidence and blocking checks for a website release or migration cutover.

Suggested additional checklists:

- project intake and inventory;
- pull-request review;
- quarterly 200-control review;
- access and credential review;
- backup restoration test;
- incident stabilization and follow-up.
